# Tata Cara Umroh (Manasik)

## 1. Ihram

Kenakan pakaian ihram dan berniat umroh di miqat.

<ArabicText>لَبَّيْكَ اللَّهُمَّ عُمْرَةً</ArabicText>

_Labbaikallahumma 'umratan_ — Aku penuhi panggilan-Mu ya Allah untuk berumroh.

## 2. Thawaf

Mengelilingi Ka'bah sebanyak 7 kali berlawanan arah jarum jam, dimulai dari Hajar Aswad.

## 3. Sa'i

Berlari-lari kecil antara bukit Shafa dan Marwah sebanyak 7 kali.

## 4. Tahallul

Mencukur atau memotong rambut sebagai tanda selesainya ibadah umroh.
